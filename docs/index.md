# 资料库索引（基线 1.0）

本库只保留 **正式版 1.0** 这一套东西，作为后续维护、更新、变更的唯一基线。1.2~4.9 的历史版本已移出本库，放在 `../_归档/历史版本_1.2-4.9/`（含 `清单.csv`），需要回滚时去那里取。

## 目录

```
资料库/
├── 00_索引.md                ← 本文件
├── 01_正式版1.0/             ← APK + 安装包 zip + 源码 zip
├── 02_源码/BMVPlayer_1.0/    ← 可直接构建的完整源码（src / res / assets / build.sh）
├── 03_面板/                  ← panel.html + panel.css（与 GitHub 仓库一致）+ 热更 zip
└── 04_文档/
    ├── 使用说明.md            ← 面向使用者
    ├── 维护手册.md            ← 面向维护：构建、版本策略、热更、调音、发布清单、约束
    ├── 变更记录.md            ← 1.0 基线 + 后续版本追加模板
    └── 基线指纹.md            ← 产物与关键源码的 SHA-256，判断是否为基线
```

## 1.0 一句话状态

包名 `com.doubao.bmv`，versionCode 32，APK 约 2.5 MB，Media3 1.4.1 内核，系统级音效，登录后 DASH 1080P，支持后台播放、等比全屏、面板 HTML/CSS 分离热更。

## 维护三条铁律

1. **只改面板的，不涨版本、不重发 APK**——改 `03_面板/` 里的 html/css，提交仓库即可。
2. **改壳能力才发 APK**，versionCode 从 32 往上递增，签名必须沿用 `tools/bmv.keystore`（否则老用户无法覆盖安装）。
3. **每次改动同步三处**：`02_源码`、内置 `assets/` 面板、`04_文档/变更记录.md`。

## 从哪开始看

- 想改样式 → `03_面板/panel.css`
- 想改面板逻辑 → `03_面板/panel.html`
- 想调音效 → `02_源码/BMVPlayer_1.0/src/com/doubao/bmv/AudioFx.java`，参数速查见 `04_文档/维护手册.md` 第 6 节
- 想重新出包 → `04_文档/维护手册.md` 第 3 节 + 第 7 节发布清单
- 判断"这是不是我基线那份" → `04_文档/基线指纹.md`
