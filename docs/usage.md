# B站 MV 播放器 使用说明（1.0）

一个纯原生 Android 播放器，用来刷 B 站音乐区的 MV / 现场。界面走远程面板，样式与结构可以线上热更；播放器、音效、登录、后台播放这些"壳能力"固定在 APK 里。

- 包名 `com.doubao.bmv`，版本 1.0（versionCode 32）
- 系统要求 Android 5.0+，APK 约 2.5 MB，无第三方运行库
- 安装：直接装 `B站MV_v1.0.apk`；从旧版升上来会保留登录态和设置（签名一致）。若曾装过别的签名版本，需先卸载。

## 一、登录与画质

1. 面板右上角点登录 → 扫码（推荐）或网页登录 / 粘贴 Cookie。
2. 登录后播放页会显示 `DASH · 1080P`；未登录时服务端按游客给流，通常只有 480P。
3. 画质行会写出取流结果与诊断信息，例如 `DASH 最高 480P 可选[32,16]`，说明该片源本身最高只有 480P，不是账号问题。
4. 播放页支持「选集」：分 P 合集按当前之后 3 首横向排列，两侧箭头翻页。

## 二、音效

播放页底部「音效」进入面板：

- 五套预设：原声直通 / 清澈人声 / 超重低音 / 3D丽音 / 深夜舒缓。戴耳机默认「清澈人声」。
- 两个精调滑杆：
  - **超低频下潜** 0–18 dB：往右推低音更沉。曲线的 38Hz 与 52Hz 双峰一起抬，兼顾"沉"和"听得见"。
  - **通透度** 0–12 dB：往右推高频更亮、更透。
- 面板底部一行诊断：`系统音效 ✓ · 均衡 ✓ · 低音 ✓ · 环绕 ✓ · 响度 ✓ · 压缩链 ✓1 · EQ最低 xxHz`。
  - `压缩链 ✓1` 是完整链（预均衡 + 多段压缩 + 后均衡 + 限幅），`✓2/✓3` 是机型降级后的简化链，`✗` 表示该机完全不支持 DynamicsProcessing，此时只靠均衡器。
  - `EQ最低 xxHz` 是系统均衡器最低频段，低于它不了的范围只能靠预均衡补。

音效全程走系统 AudioEffect（AudioFlinger 层），不会因为处理不过来而自动关闭。

## 三、后台播放

- 按 Home 或锁屏，声音继续播；通知栏出现常驻卡片，带上一首 / 暂停 / 下一首。
- 锁屏界面与蓝牙耳机（含索尼耳机播放键）可以直接控制；拔耳机自动暂停。
- 点通知回到播放页。
- 把 App 从后台任务列表划掉，播放会停止（播放器实例依附于播放页）。

## 四、全屏

- 右下角 ⛶ 进全屏：横屏、隐藏状态栏与导航栏，画面保持 16:9 不拉伸（屏幕更宽时两侧留黑边）。
- 全屏右上角有半透明「⤡ 小屏」胶囊，点一下回竖屏。
- 全屏**最左边沿 26dp 的一条窄缝**点一下，弹出「接下来」浮层：贴左显示，最多 4 首，点哪首放哪首。
- 一集播完会自动下一首，最后一集播完自动停。

## 五、面板热更

面板由 `panel.html` + `panel.css` 组成，托管在 GitHub 仓库 `q137663972-alt/bmv-panel`：

1. 改样式只动 `panel.css`，改结构/逻辑动 `panel.html`；
2. 提交后 App 启动会拉取，或在面板底部页脚点「检查热更」→「立即应用」；
3. 远程连不上时用上次缓存，再不行用内置面板与内置 CSS，界面不会白屏。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 登录了还是 480P | 该合集本身最高 480P；或登录态失效（面板会提示），重新扫码即可 |
| 播放失败 / 一直转圈 | 点「重试」；仍不行点「网页高清·弹幕」走 WebView 通道 |
| 低音听着"假" | 已停用 BassBoost 类虚拟低频；把「超低频下潜」收到 8–12 dB 更自然 |
| 音效面板显示 `压缩链 ✗` | 该机型不支持 DynamicsProcessing，滑杆仍作用于均衡器，可反馈机型号 |
| 全屏看不到「小屏」按钮 | 1.0 已修（按钮挂根容器），旧版请升级 |
| 画面被拉伸 | 1.0 已修（按真实比例计算），旧版请升级 |
